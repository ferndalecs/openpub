## web/shapes.js

The outlines of the Office autoshapes follow the shape definitions Microsoft publishes in its
Office drawing format specification ([MS-ODRAW]), covered by the Microsoft Open Specifications
Promise.

## Rust crates

The desktop program and the library use crates from crates.io (listed in `Cargo.toml` /
`Cargo.lock`), each under its own licence - mostly MIT and/or Apache-2.0. They are downloaded
when building and are not part of this repository; release binaries include them compiled in.
`cargo install cargo-about` (or `cargo-license`) lists them with their licences.

## Microsoft Edge WebView2

OpenPub draws its window with the WebView2 runtime that ships with Windows 10/11. It is not
included in this repository or the installers.
