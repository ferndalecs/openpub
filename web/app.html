Convert a whole folder

Turn every Publisher file in a folder (and the folders inside it) into another format in one go. The new files are saved next to the originals, which aren't changed; files already converted are skipped. You can carry on working while it runs.

Print

Choose how to print. Windows' print window opens next, to choose the printer.

Printing a booklet

  1. In the print window, choose Print on both sides and Flip on short edge (the names vary between printers).
  2. Choose Landscape if the printer asks.
  3. Fold the stack of sheets in half, with the first page on the outside, and staple along the fold.

Blank pages are added at the end when the number of pages isn't a multiple of 4. A printer that can't print on both sides can print the odd sheets first, then the even ones on the back.

    Help

    How to do the most common things. Hover over any button to see what it does.

    Add text

    Insert > Text box, then click on the page (or drag to choose the size) and type. To change text, double-click it - or click the box once and just start typing.

    Change the font, size or colour

    Select the words (or click the box's edge for all of it), then use the Home tab. The font and size boxes open lists; the colour box opens a palette.

    Add a picture

    Drag a picture from File Explorer onto the page, paste one with Ctrl+V (a screenshot works too), or use Insert > Picture.

    Add a shape or a line

    Insert > Shapes (or Rectangle, Ellipse, Line), then click on the page or drag to draw it. Hold Shift for a square, a circle or a straight line.

    Add WordArt

    Insert > WordArt, type your words in the box that appears, then press Esc. Double-click WordArt to change its words.

    Line things up

    Drag objects: pink lines show when they line up with the page edges, the middle of the page or each other. Hold Alt to place freely. Shape Format > Align lines up several at once.

    A red ! on a text box

    Some of the text doesn't fit. Click the !, then Make box fit text or Shrink text to fit - or drag the box bigger.

    Welsh letters (ŵ, ŷ, â...) and symbols

    Insert > Symbol while typing. Or press Ctrl+Shift+6, then the letter: w gives ŵ. Ctrl+' then a letter gives é.

    Text around a picture

    Select the picture (or shape), then Shape Format > Wrap text: Square or Tight to flow text round it, Top and bottom, In front of text, or Behind text for a background.

    Page numbers

    Insert > Page number. To number every page, do it on the master page (Page > Master page).

    Carry text on into another box

    For an article that continues on another page: select its text box, Text Box > Link to text box, then click an empty text box (or an empty part of a page for a new one). Break link stops it again.

    Undo a mistake

    Ctrl+Z takes back the last change (again for the one before); Ctrl+Y puts it back.

    Save your work

    Ctrl+S. OpenPub saves an OpenPub (.opub) file; a Publisher (.pub) file you opened is left as it was. Unsaved work is kept in a recovery copy and offered back if OpenPub closes unexpectedly.

    Make a PDF or print

    File > Export > PDF to hand in or share; File > Print (Ctrl+P) to print.

    Print a folded booklet

    File > Print > Print as a folded booklet, then print on both sides, flipping on the short edge. Fold the stack in half and staple it.

    Pages

    The Page tab adds, copies, deletes and moves pages, and changes the page size, background and border. Things on the master page appear on every page.

    Right-click

    Right-click an object for copy, paste, delete, bring to front and more; right-click an empty part of the page to add a text box there.
